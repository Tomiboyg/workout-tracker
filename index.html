Workout Tracker

Vlož svoje Supabase prihlasovacie údaje pre ukladanie dát do cloudu.

1 Choď na supabase.com → New project
2 Settings → API → skopíruj URL a anon key
3 SQL Editor → spusti init script (tlačidlo nižšie)

SQL Init Script

Skopíruj a spusti v Supabase → SQL Editor → New query

create table if not exists workouts (
  id bigint primary key,
  name text,
  date text,
  duration int,
  exercises jsonb
);

create table if not exists custom_exercises (
  id bigint primary key,
  name text,
  group_name text
);

💡 Ako funguje e1RM?

e1RM = váha / RPE_percent[reps][rpe]
